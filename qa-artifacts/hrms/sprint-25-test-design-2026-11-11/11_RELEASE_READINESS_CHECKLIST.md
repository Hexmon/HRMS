# Completion And Release

For a behavior ticket Done requires approved oracle, implementation, all applicable planned/added cases actually passing, meaningful unit/component assertions, 100% changed executable line evidence with every changed decision branch, real boundary/browser evidence, independent review and no unresolved material defect. Unused/dead code should be removed; reachable lines cannot be hidden with ignores or skips. No finite test suite establishes all possible inputs.

Record case results with exact source head, command, environment, observed output/state, reviewer and sanitized evidence/defect link. Required Failed/Blocked/Not Tested cases keep completion pending. N/A requires reviewed rationale; an owner exception is explicit and is not full coverage.

The source-only task and new case design do not execute this gate. QA-S25-003 tooling is still a prerequisite. Hosting/penetration/human UAT and deployment remain separately authorized. Preserve previous sprint statuses and all story points.
