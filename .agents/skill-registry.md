## Loop Routing

| Loop | Selected skills/guidance | Reason and boundary |
| --- | --- | --- |
| 0 — skill preparation | `find-skills`, `skill-creator`, `qa-master-checklist`, `verify-change` | Discover candidates, reject incompatible workflows, define and validate focused project skills. |
| A — repository | `hrms-codebase-discovery`, QA repository inspection | Map evidence before asking owners; avoid assuming docs or generated output are live behavior. |
| B — product | QA business discovery and stakeholder dialogue | Capture decisions and test oracles; do not invent unresolved HR/payroll rules. |
| C — architecture | `hrms-architecture-review`, `security-review` when trust boundaries apply | Trace current paths and failure modes; ADRs remain proposals until approved. |
| D — local journeys | QA journey design, `verify-change`, `hrms-product-ui` for affected screens, `security-review` for authorized local abuse cases | Browser evidence plus targeted checks; no production probes. |
| E — reconciliation | QA traceability, `verify-change`, `skill-creator` for observed skill defects | Update canonical sources and backlog using demonstrated gaps. |
