## Primary Guidance Used

- [Playwright best practices](https://playwright.dev/docs/best-practices): test visible behavior, isolate cases, use resilient locators and web-first assertions. Prefer an observable ready condition to a generic network-idle sleep.
- [Vitest coverage](https://vitest.dev/guide/coverage): coverage needs a configured provider and instrumented execution. Existing normal test runs do not imply line/branch reports. QA-S25-003 owns actual unit/component and diff-coverage setup.
- [OWASP WSTG](https://owasp.org/www-project-web-security-testing-guide/) and [API Security](https://owasp.org/API-Security/): reference applicable abuse and authorization categories; do not interpret a checklist as a completed penetration test.

No reviewed external skill can guarantee every possible user input. The selected approach combines approved decision tables, boundaries, state/property tests, real infrastructure failures, rendered user journeys and independent review. Maintain explicit residual gaps. The 482 initial Sprint 25 cases cover 128 leaf tasks with 12 parent rollups; all are Not Tested, and cases needing owner decisions remain provisional.
